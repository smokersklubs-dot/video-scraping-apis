# SKLUBS Box Configurator

Configurateur de boîtes personnalisées à **moteur paramétrique** : les dimensions produisent la structure, le patron 2D (SVG) et le modèle 3D (Three.js) à partir d'une seule géométrie. Aucun modèle 3D statique.

```bash
npm install
npm run dev
npm test
```

Documentation complète : [`../docs/box-configurator/`](../docs/box-configurator/) — commencer par `ARCHITECTURE.md` puis `HANDOFF.md`.

Structure de référence : **BOX-001** (boîte pliante à languettes). Les hypothèses de fabrication non validées sont marquées `PACKAGING_VALIDATION_REQUIRED` dans le code et la documentation.
